About

Demo Trajectory Generator

Phase 2: Web UI

Features

  • Interactive map-based launch/landing point selection
  • Real-time feasibility checking against vehicle envelope
  • Full trajectory computation with altitude, Mach, and time-series charts
  • 3D visualization with CesiumJS
  • Advanced vehicle configuration editor

⚠️ Important Disclaimer

All vehicle parameters and simulation results are NOTIONAL DEMO VALUES ONLY for demonstration purposes. They do NOT represent any real vehicle design, operational system, or actual performance characteristics.

Model

3-DOF point-mass simulation with:

  • Two-stage vehicle + reentry vehicle (RV)
  • US Standard Atmosphere 1976
  • Spherical rotating Earth
  • Sutton-Graves stagnation heating

Authentication

This demo uses simple password authentication for single-user access. The password is configured via the APP_PASSWORD environment variable.
